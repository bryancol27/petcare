# Guía de estilos visual — UI Kit PetCare

## Propósito

El UI Kit de PetCare reúne los estilos y componentes visuales que sirven como base común para las pantallas del MVP. Su propósito es mantener una experiencia coherente, facilitar la comprensión de las acciones disponibles y permitir que los elementos se reutilicen durante el diseño y la maquetación inicial.

## Fundamentos visuales

- **Color:** la interfaz utiliza tonos verde azulado y turquesa como colores principales de marca y acción, acompañados por fondos claros, superficies blancas y tonos neutros para separar y jerarquizar la información.
- **Tipografía:** se combinan Manrope para encabezados y DM Sans / Plus Jakarta Sans para textos de interfaz, priorizando lectura clara y jerarquía entre títulos, etiquetas y contenido.
- **Forma y espaciado:** tarjetas y controles usan bordes suaves, radios consistentes, divisores sutiles y espacios suficientes para distinguir grupos de información.
- **Iconografía:** los iconos acompañan las etiquetas y acciones; no reemplazan instrucciones o nombres visibles.

## Componentes contemplados

- Botones primarios, secundarios y de acción contextual.
- Campos de texto, selectores, búsqueda y controles de fecha.
- Etiquetas de estado, insignias y mensajes de ayuda o validación.
- Tarjetas para mascotas, prestadores, servicios y citas.
- Elementos de navegación para landing, panel de tutor y panel de prestador.
- Estados de interacción, como selección, favorito, disponibilidad, confirmación y error.

## Usabilidad y accesibilidad

El sistema busca que las acciones principales sean reconocibles por su texto y ubicación, que los formularios tengan etiquetas comprensibles y que los estados no dependan únicamente del color. Los componentes deben mantener contraste legible, foco visible al navegar con teclado, áreas interactivas cómodas y una disposición adaptable a escritorio y móvil.

## Aplicación al MVP

Los estilos y componentes del UI Kit se aplican en las pantallas de acceso y registro, los paneles del tutor y prestador, el catálogo de servicios, el flujo de reserva y la confirmación. La maquetación HTML/CSS inicial debe conservar la jerarquía, los componentes y la apariencia definida en Figma.
